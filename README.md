# Chess Club Jeopardy

A GitHub Pages version of the Chess Club Jeopardy game originally created in Canva.

## Files

- `index.html` — page structure
- `style.css` — all styling
- `script.js` — questions, answers, board generation, and game logic

## Edit the questions

Open `script.js`.

The three main sections to edit are:

- `categories`
- `questions`
- `answers`

Each category has 5 questions, matching the 100–500 point rows.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Set the source to your main branch and `/ (root)`.
5. Save and wait for GitHub Pages to deploy.

The Pexels background image is currently loaded from its external URL, so no image file is required.
